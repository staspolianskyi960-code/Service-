# Склад запчастин

Програма обліку запчастин для автосервісу. Працює в браузері на телефоні, планшеті й комп'ютері.

- Живий сканер штрихкодів камерою (деталі та VIN)
- Розпізнавання тексту з фото прямо на пристрої
- Розшифровка VIN через безкоштовну базу NHTSA
- Прихід / видача, мінімальні залишки, історія
- Фото деталей, пошук по VIN, імпорт і експорт Ексель

Дані поки зберігаються на пристрої (IndexedDB).
